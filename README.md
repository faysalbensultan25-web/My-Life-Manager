# My Life Manager — v1.0 MVP

Flutter Android-first personal life + money manager.

## Included
- Home dashboard / wall-style layout
- To-Do list
- Daily notes
- Income / expense entries
- Custom categories
- Recent history
- Monthly summary
- Basic statistics
- Local persistence with SharedPreferences
- AdMob test banner and test interstitial hooks

## Run
1. Install Flutter SDK.
2. `flutter pub get`
3. `flutter run`

## Build Play Store bundle
`flutter build appbundle --release`

## AdMob
The code uses Google's official Android test ad unit IDs. Replace them with your own AdMob IDs only after the app is tested. Never publish with test IDs.
